# Frontend Setup — Next.js 15

Folder ini berisi setup awal frontend berbasis **Next.js 15** dengan **TypeScript** dan **Tailwind CSS**.

## Struktur
```
frontend/
├── src/
│   └── app/
│       ├── layout.tsx   # Root layout
│       ├── page.tsx     # Halaman utama
│       └── globals.css  # Global styling
├── next.config.ts
├── tailwind.config.ts
├── postcss.config.mjs
├── tsconfig.json
└── package.json
```

## Menjalankan
```bash
npm install
npm run dev
```
